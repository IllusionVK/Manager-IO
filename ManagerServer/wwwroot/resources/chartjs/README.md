# Chart.js resources

These browser bundles are vendored so Manager Server and Manager Desktop can render charts without a CDN connection.

- `chart.umd.min.js`: Chart.js 4.5.1, from the `chart.js` npm package.
- `chartjs-chart-sankey.min.js`: chartjs-chart-sankey 0.19.1, from the `chartjs-chart-sankey` npm package.
- `chartjs-plugin-datalabels.min.js`: chartjs-plugin-datalabels 2.2.0, from the `chartjs-plugin-datalabels` npm package.

Both packages use the MIT license. Their license files are included in this directory.
